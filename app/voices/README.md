# 音色目录

她的声音完全来自这里：TTS 是克隆式的，没有内置音色表，听到的嗓音就是某段
参考录音的嗓音。换声音 = 换这个目录里的一份录音。

**平时不用手动改这里。** 打开界面 → 设置 → 声音，上传、切换、删除都在那儿，
切换立刻生效，不用重启。下面写的是目录约定，方便你直接放文件或排查问题。

## 自带的音色

源码仓库不包含默认参考录音。二进制整合包如果附带示例音色，发布者必须保留其
生成来源和授权记录，并确认允许再分发。想要别的嗓音，可以在设置面板里上传。

如果你要换成**真人的声音**（自己的、朋友的、影视或游戏里的配音），先想清楚：

- 自己录制并有权使用的声音，可以作为个人参考音色。
- 别人的声音，得当事人同意。
- 影视、动画、游戏里的配音，既是作品版权，也是配音演员的人格权益 ——
  自己留着玩没人管，但**不要打包分发出去**。

## 目录约定

```
voices/
├── .active               当前用哪个音色（界面切换时自动写，别手改）
└── 我的声音/
    ├── ref_audio.wav     参考音频
    └── ref_text.txt      这段音频逐字对应的文本（UTF-8）
```

文件夹名就是音色名，会显示在设置面板的音色列表里。

### 参考音频要求

| 项目 | 要求 |
|---|---|
| 时长 | 3~10 秒最佳（超过 20 秒会被自动截断） |
| 内容 | **单一完整句子**，不要跨句截取 |
| 音质 | 干净人声，无背景音乐、无混响、无杂音 |
| 格式 | wav / mp3 / flac / m4a / ogg / aac，界面上传时自动转成 16k 单声道 |

> ⚠️ **不要跨句截取**：参考音频里包含多个句子时，合成结果可能混入参考音频的内容片段。
> 宁可用一句 5 秒的，也不要用一段 15 秒的对话。

手动放文件的话，自己转一下格式：

```bash
ffmpeg -i 你的录音.mp3 -ac 1 -ar 16000 -c:a pcm_s16le ref_audio.wav
```

（整合包自带 ffmpeg，在 `runtime\ffmpeg\ffmpeg.exe`）

### ref_text.txt 要求

必须和录音**逐字一致**，标点也要对上。这个文本的准确度直接决定克隆质量 ——
对不上的话，合成出来的声音会明显不像。

界面上传时这一项是必填的，没有它克隆出来的声音会飘。

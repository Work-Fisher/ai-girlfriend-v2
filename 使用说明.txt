AI 女友 · Windows 一键包
========================

最快开始（纯语音）
------------------
1. 把整个文件夹解压到**纯英文、无空格**的路径，比如 D:\AI-Girlfriend
   （必须英文：数字人引擎跑在 WSL 里，中文路径它看不见）
2. 直接双击「一键启动.cmd」—— 浏览器会自己打开；没装 WSL 也能进入纯语音模式
3. 右上角「设置」里填一个语言模型 API Key，就可以先用包里的默认声音聊天

想开数字人，再双击「首次安装.cmd」。它会请求一次 Windows 管理员授权并自动配置 WSL2。
如果这台电脑从没启用过 WSL，Windows 会要求重启；重启后再双击一次，它会接着导入引擎。

想换成自己的角色和声音，再到设置里上传：
  · 角色影像 —— 5~15 秒正脸视频，她的脸和口型从这儿来
  · 声音 —— 3~10 秒录音 + 对应逐字文本，她的嗓音从这儿克隆

API Key 必须自己去对应平台申请，包里不含，所以首次使用不可能完全零配置。


机器要求
--------
· Windows 10 / 11 64 位
· NVIDIA 显卡。实测 RTX 4070 Ti（12G 显存）全栈常驻约 7G，渲染口型时更高。
  8G 显存建议关掉数字人，纯语音对话很轻松。
· CPU 虚拟化要开（任务管理器 → 性能 → CPU，看「虚拟化」是不是「已启用」）
· 磁盘留 35 GB 以上：包本身 14.5 GB，导入数字人引擎还要再展开约 11 GB
· 不需要预装 Python、CUDA、FFmpeg、Docker —— 全都在包里

联网只用于调语言模型的 API。语音识别、语音合成、口型生成全部在本地跑。


不想要数字人？
--------------
数字人是可选的。不跑「首次安装.cmd」也能用；直接双击「一键启动.cmd」会自动进入纯语音对话，
省一大块显存，响应也快很多。

已经装了想临时关掉：界面左下角有个「数字人」开关，随时切。


她记得住事
----------
换了模型、重启了电脑，她都还记得你说过的话——聊天记录存在本地，
下次开机会自动接上。不是"假装记得"，是真的把上一段对话接着往下聊。

想让她彻底忘掉重新开始：删掉 app\dsh-bridge\dsh-home\sessions 这个文件夹。


东西都在哪儿
------------
你的数据（备份的话备份这些就够）：
  app\heygem-data\        角色视频、待机视频、好感度、界面设置
  app\voices\             音色
  app\config\characters.json   人设
  app\heygem-data\llm-provider.json   API Key（明文，别外传）
  app\dsh-bridge\dsh-home\sessions\   聊天记录

生成的东西：
  app\output\audio\  app\output\video\

出问题看日志：
  app\logs\


不太对劲的时候
--------------
· 说话没反应
  先看浏览器有没有给麦克风权限（地址栏左边的小图标）。
  界面右上角显示「已在新窗口连接」= 你开了第二个标签页，关掉多余的。

· 一直转圈，她不说话
  多半是 API Key 没填或者余额没了。设置 → 服务，看「语言模型」那行。

· 有声音但没有画面
  数字人引擎没起来。关掉再打开一次；还不行就看 app\logs\duix.stdout.log。
  引擎冷启动要一到三分钟，第一次慢是正常的。

· 显存不够 / 画面卡顿
  关掉左下角的「数字人」开关，纯语音对话很省。

· 双击 cmd 闪一下就没了
  在文件夹空白处按住 Shift 右键 →「在此处打开 PowerShell 窗口」，
  然后输入 .\一键启动.cmd 回车，这样报错信息能留在屏幕上。


端口
----
全部只绑 127.0.0.1，不对外：
  7860  界面        8766  语音管线      8790  语言模型桥接
  8791  语音合成    8383  数字人引擎（在 WSL 里）

哪个端口被别的软件占了，启动时会直接报出来。


卸载
----
1. 删掉整个文件夹
2. 数字人引擎单独删：PowerShell 里执行 wsl --unregister DuixDistro
